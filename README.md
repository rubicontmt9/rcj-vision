# RCJ Vision

RoboCupJunior サッカー(IR ボール)の機体に載せる、スマホ(Android)用の視覚モジュールです。
スマホのカメラでボール・ゴール・味方/相手ロボットを検知し、スマホを原点とした座標・進路予測・IMU 情報を
USB(OTG)シリアルでマイコンへ出力します。

## できること

- 色ベースの検知(CameraX、YUV 直読み + 早見表で約 30fps @ 320x240)
  - ボール: オレンジ / ゴール: 黄・青 / 味方: マゼンタのマーカー / 相手: シアンのマーカー
- 画素 → 床面への投影でロボット座標(mm)を算出。重力ベクトルで床面を決定
  - 原点 = スマホ、+Y = 背面カメラの向き、+X = 右。前面カメラの物体は Y < 0
- α-β フィルタで追跡し、速度・0.5 秒後の位置・最接近時間・Y=0 ライン通過時間を予測
- ジャイロで自機の回頭を補正、加速度から自機速度の目安を出力
- 現場での色キャリブレーション(「校正ON」→ 対象を選択 → 画面の物体をタップ。結果は端末に保存)
- 競技モード: プレビュー停止・画面真っ黒・USB 自動接続(`--ez competition true` で起動、2 秒長押しで解除)
- 前後カメラ同時利用に非対応の端末では、背面/前面を交互に切り替え

## USB 出力フォーマット

1 行 1 パケット、`$` と `*` の間の文字の XOR をチェックサム(16 進 2 桁)に付けた NMEA 風テキストです。

```
$IMU,t_ms,heading,roll,pitch,ax,ay,az,gx,gy,gz,egoVx,egoVy*CS
$OBJ,t_ms,cls,id,cam,x,y,vx,vy,x500,y500,tca_ms,dca_mm,cross_ms,crossX,conf*CS
```

- `cls`: `B` ボール / `Y` 黄ゴール / `U` 青ゴール / `A` 味方 / `O` 相手
- `x,y` [mm]、`vx,vy` [mm/s]、`x500,y500` は 0.5 秒後の予測位置
- `tca_ms`/`dca_mm`: スマホ原点への最接近までの時間と距離、`cross_ms`/`crossX`: Y=0 を横切るまでの時間とそのときの X(横切らない場合 -1)

受信側のサンプル: [`esp32-receiver/esp32-receiver.ino`](esp32-receiver/esp32-receiver.ino)(XIAO ESP32S3、CDC On Boot: Enabled)。
CH340/CP210x/FTDI などの USB シリアル IC と、RP2040・STM32・ESP32-Sx・CH32 のネイティブ CDC に対応します。
ESP32-S3 内蔵 USB は DTR/RTS でリセットされるため、アプリ側では触らない実装です。

## ビルド

JDK 17、Android SDK 34、Gradle 8.7 が必要です。AGP は日本語などの非 ASCII パスでビルドに失敗するため、
`build.sh` は ASCII パスにコピーしてビルドします(パスは自分の環境に合わせて編集してください)。

```bash
./build.sh   # app-debug.apk を生成
```

## 既知の制約

- 色の範囲は初期値です。会場の照明に合わせてキャリブレーションしてください。
- 前後カメラ同時利用に対応しない端末では、前面の更新頻度が下がります。
- 自機速度は加速度の減衰積分による目安で、ドリフトします。
